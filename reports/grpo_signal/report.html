GRPO 试点：按参考类别拆分的学习信号

作业 5066266：187 步，每步 16 个 prompt × 8 条回答，训练集 grpo-02（每类 1,500 个 prompt）。每个 checkpoint t 用它当时的采样权重，在训练器接下来 25 步（t+1 到 t+25）实际用到的 prompt 上，由温度 1 下决定 token 的概率算出每组 8 条回答的期望结果（作业 5070642，scripts/grpo_signal_by_reference.py）。每步用到哪些 prompt 由 TRL 的抽样顺序（种子 42）重建，并对照了训练日志。

采样权重 = 推给 vLLM、真正用来抽 rollout 的 bf16 合并权重；训练策略 = HF + PEFT。零方差组 = 8 条回答奖励全相同（全对或全错），没有梯度；有信号的组 = 其余的组。

校验：第 0 步（SFT）的 token 概率对照已存的真实采样

已存采样：GRPO 数据构建时 vLLM 从合并的 SFT 模型在同一批行上抽的温度 1 样本（hire 行 32 个，reject 行 8 个）；零方差用无偏估计（任取 8 个全一致的概率）。留出行是在类内随机抽的，是干净的对照；训练行是按这些样本挑出来的（tipped 行至少有一个错样本），所以它们的已存样本会比重新抽样错得多。
